# 🧠 Картирование знаний и дашборд компетенций

> **Статус:** Завершен  
> **Роль:** Бизнес-аналитик / Аналитик данных  
> **Стек:** Power BI, Excel (Power Query), Gephi, таксономия знаний

---

## 📌 Бизнес-проблема

Руководители структурного подразделения тратили **от 2 до 8 часов в неделю** на ручной поиск экспертов для проектных задач. Процесс включал:
- Личные звонки и сообщения коллегам;
- Ведение заметок в хаотичном формате;
- Принятие кадровых решений на основе интуиции, а не данных.

Это приводило к:
- Задержке старта проектов на **1–2 недели**;
- Ошибкам в подборе команды (выбирались «проверенные», а не релевантные специалисты);
- Отсутствию объективной картины дефицита компетенций в отделе.

---

## 🎯 Цель проекта

Разработать методологию и инструмент для:
- Визуализации экспертных профилей сотрудников;
- Поиска специалистов под конкретные задачи за минимальное время;
- Выявления «слепых зон» в знаниях команды для планирования обучения.

---

## 🛠 Инструменты

| Инструмент | Назначение |
|------------|------------|
| **Power BI** | Интерактивная визуализация дашборда |
| **Excel / Power Query** | ETL-подготовка и автоматическая обработка данных опросов |
| **Gephi** | Визуализация социальных связей экспертов |
| **Таксономия знаний** | Классификация компетенций по уровням и направлениям |

---

## 🔍 Мой подход (как решала)

1. **Провела интервью с заказчиком** — выявила, какая информация о персонале критична для управления проектами.
2. **Разработала таксономию знаний** — структурировала компетенции по направлениям и уровням (1–5).
3. **Создала анкету для сбора данных** — унифицированный опрос для 60+ сотрудников.
4. **Спроектировала модель данных** — связала сущности «Сотрудник — Навык — Уровень — Направление».
5. **Разработала интерактивный дашборд** с фильтрами по подразделениям, специализациям и уровню экспертизы.
6. **Внедрила процесс обновления** — руководитель загружает новый опрос в Excel, дашборд обновляется автоматически (за счёт Power Query).

---

## 📊 Результаты

- Загружены данные по **60+ сотрудникам** и **5+ направлениям**;
- Выявлен дефицит экспертизы: в одном направлении **33 сотрудника** имеют уровень знаний **не выше 3 из 5**;
- Определены сотрудники, готовые развиваться в новых областях;
- **Сокращение времени поиска эксперта:** с 2 часов до **5 минут** (в 24 раза).

## ⚠️ Ограничения и планы развития

**Текущие ограничения:**
- Данные обновляются **раз в месяц** (опрос занимает 20–30 минут у сотрудника, частое проведение невозможно из-за загрузки);
- На данный момент покрыт **1 отдел** (из 5 потенциальных);
- Полная автоматизация невозможна из-за перегрузки серверов (обработка больших опросов приводит к зависанию системы).

**Планы развития:**
- Интеграция с HR-системой для автоматического добавления новых сотрудников в пул;
- Типизация направлений для снижения нагрузки на сервер;
- Масштабирование на все отделы компании;
- Внедрение алгоритма рекомендаций («Кто лучше всего подойдёт под этот проект?»).
