## 📌 О проекте

Проект выполнен на основе **реального брифа от сервиса Самокат** в рамках хакатона Яндекс Практикума. Мы работали с задачей, которая ранее была предоставлена практикуму реальным заказчиком.

### Проблема
Пользователи ищут рецепты в сторонних сервисах — Самокат теряет сценарий использования. Текущий раздел с рецептами в формате сторис неудобен:

- ❌ Нет категорий  
- ❌ Нет текстового описания  
- ❌ Нельзя менять порции  
- ❌ Нельзя добавлять ингредиенты в корзину  
- ❌ Архив старых рецептов не используется  

### Бизнес-цель
Рост удержания пользователей через сценарий **«Самокат как источник рецептов»**.

## 📊 Ключевые результаты (KPI)

| Метрика | Целевое значение |
|---------|------------------|
| Рост MAU раздела «Рецепты» | **+30%** через 3 месяца |
| Рост конверсии «Просмотр → Корзина» | **+5 п.п.** |
| Сокращение времени сбора корзины | **−40%** |
| Рост сохранённых рецептов | **+25%** |
| Повторно опубликованных архивных рецептов | **не менее 50 шт.** |

## 🚀 Что дальше

Решение готово к разработке. По итогам хакатона проект получил **положительную оценку эксперта**. Рекомендованные следующие шаги:

2. **Сбор метрик** через 1 месяц → корректировка KPI  
3. **Бэклог:** голосовое управление, персональные рекомендации, интеграция с Health
