# 📊 Анализ трудозатрат и выручки (дашборд эффективности)

> **Статус:** ✅ Внедрён  
> **Роль:** Аналитик данных  
> **Данные:** 100+ сотрудников, 10+ проектов, 8 направлений  

---

## 📌 Задача

Создать инструмент для анализа распределения ресурсов, оценки эффективности проектов и управления загрузкой сотрудников.

---

## 🛠 Инструменты

| Инструмент | Назначение |
|------------|------------|
| **Power BI** | Построение дашборда |
| **Excel / Power Query** | Подготовка и обработка данных |
| **DAX** | Расчёт ключевых метрик |

---

## 🔍 Подход

1. **Сбор данных:** структурированы данные по трудозатратам, выручке и ролям участников проектов.
2. **Построение дашборда:** созданы разрезы по:
   - Продуктовым направлениям
   - Функциям сотрудников (эксперты, интеграторы, координаторы и др.)
   - Уровням специалистов
   - Проектам и месяцам
3. **Расчёт метрик:** разработаны формулы в DAX для автоматического расчёта эффективности.

---

## 📊 Результаты

| Показатель | Значение |
|------------|----------|
| Охват | **100+ сотрудников**, **10+ проектов**, **8 направлений** |
| Трудозатраты | Общие и средние по направлениям |
| Выручка | По направлениям и проектам |
| Уникальные сотрудники | По функциям |
| Активность | По месяцам |

---

## 💰 Бизнес-эффект

| Проблема | Решение | Результат |
|----------|---------|-----------|
| Руководители тратили **до 3 часов в неделю** на сбор данных из разных Excel-файлов | Все данные доступны в Power BI в 1 клик | Экономия: **~120 часов/год** на одного руководителя |
| 60% трудозатрат экспертов уходило на низкомаржинальные проекты | Дашборд показал неэффективное распределение ресурсов | Перераспределение → **рост выручки на 15%** без найма новых сотрудников |
| Невозможно было быстро оценить рентабельность направления | Отчёт по выручке и затратам в реальном времени | Управленческие решения стали **данными, а не интуицией** |
