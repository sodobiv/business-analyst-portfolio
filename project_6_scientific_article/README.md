## 📌 Тема

Исследование применения онтологий (графов знаний) для моделирования карт знаний и управления данными в организациях.

---

## 🛠 Методология

| Этап | Описание |
|------|----------|
| **Теоретический анализ** | Изучены подходы к управлению знаниями и интеграции онтологий с ИИ |
| **Построение модели** | Разработана онтология (граф знаний) для структурирования экспертизы |
| **Разработка процесса** | Создана концепт-карта и 8-шаговый метод сбора и обработки данных |
| **Применение** | Модель протестирована на данных организации |

**8-шаговый метод сбора данных:**
1. Выявление потребности организации
2. Проведение опроса (универсального и кастомизированного)
3. Сбор данных
4. Обработка данных
5. Моделирование карты знаний
6. Визуализация данных с помощью ИИ
7. Валидация
8. Отчёт с рекомендациями
