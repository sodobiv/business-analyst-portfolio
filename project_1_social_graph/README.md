# 🕸️ Картирование социального графа

> **Статус:** ✅ Завершён  
> **Роль:** Бизнес-аналитик / Аналитик данных  
> **Команда:** 100+ сотрудников  

---

## 📌 Задача

Проанализировать коммуникации в команде из 100+ сотрудников для выявления скрытых лидеров, «брокеров знаний» и улучшения кросс-функционального взаимодействия.

---

## 🛠 Инструменты

| Инструмент | Назначение |
|------------|------------|
| **Gephi** | Построение и визуализация графа |
| **Excel / Power Query** | Подготовка и очистка данных |
| **Betweenness centrality** | Выявление «брокеров знаний» (соединяют разные группы) |
| **Eigenvector centrality** | Оценка влиятельности узлов |
| **Модульность** | Выделение кластеров (сообществ) |

---

## 🔍 Подход

1. **Сбор данных:** проведены опросы о том, к кому сотрудники обращаются за советом по различным направлениям.
2. **Построение графа:** узлы — сотрудники, рёбра — рекомендации (вес — частота упоминаний).
3. **Расчёт метрик:** вычислены центральности для выявления ключевых фигур.
4. **Кластеризация:** выделены сообщества с помощью модульности.

---

## 📊 Результаты

| Показатель | Значение |
|------------|----------|
| Количество кластеров | **5** (связанность от 12% до 26%) |
| Новые «брокеры знаний» | **5 сотрудников** (соединяют разные группы) |
| Руководители на периферии | ✅ обнаружены — признак децентрализованного сообщества |
| Эксперты в центре | ✅ подтверждено — сообщество живёт за счёт экспертизы, а не иерархии |

**Ключевой инсайт:**  
Мы нашли 5 сотрудников, которые соединяют разные отделы. Они не занимают руководящих должностей, но являются «мостами» в коммуникациях. Это позволило точечно назначить их модераторами для улучшения кросс-функционального взаимодействия.

---

## 💰 Бизнес-эффект

| Проблема | Решение | Результат |
|----------|---------|-----------|
| Поиск эксперта через «сарафанное радио» занимал **до 2 часов** | Руководитель видит всю сеть контактов на графе | Поиск эксперта **за 5 минут** |
| Непонятно, кто соединяет отделы | Выявлены 5 «брокеров знаний» | Назначены модераторы → улучшение коммуникаций |
| Коммуникации хаотичны | Выделены 5 кластеров | Понятно, где нужны дополнительные мосты |

**Экономия времени:**  
~1,5 часа в неделю на каждого руководителя → ~100 000 руб./год на одного руководителя.
